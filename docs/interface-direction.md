# Winmux workspace design

## Direction contract

THESIS: A quiet personal workbench for long sessions with terminal agents. The previous edge-to-edge grid of boxed headers felt bulky and spreadsheet-like; this revision replaces its composition rather than merely recoloring it.

OWN-WORLD: Graphite shell, slightly lifted terminal surfaces, desaturated mint focus and warm amber attention. Rounded terminal corners and narrow empty gutters replace continuous grid lines. The original WM creature mark carries the identity; functional areas stay calm.

STORY: Identify the project, focus a shell, split when needed, and open project tools without losing context. Process state stays factual. Repeated pane actions appear on hover or keyboard focus while primary project tools remain discoverable.

FIRST VIEWPORT: A compact 208px navigation rail with the WM mark and a sparse project list; a 52px workspace bar; inset terminal surfaces separated by 8px gutters. A tiny footer carries environment and directory. No decorative dashboard cards or counters.

FORM: Desktop workbench, selected from the user's explicit request for a distinctive minimal replacement of the angular grid. The external design launcher was unavailable earlier in the session; no generated concept selection or design-tool approval is claimed.

FINISH: Capture the real Electron app in dark, light and compact states, inspect the working controls and record the actual result. README screenshots come from this running application, not a mockup.
