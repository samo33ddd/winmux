# Winmux workspace design

Winmux is a quiet Windows workbench for terminal agents. A 200px project rail and 48px workspace header leave most of the window to the active shell. A 38px terminal tab strip scrolls horizontally, and each terminal keeps a compact 32px factual status row with a constrained accent line.

The default scene is near-black graphite with slightly lifted terminal and tool surfaces, 1px neutral separators, 4px control or pane radii and a single desaturated mint focus accent. Amber is reserved for attention; red is reserved for errors. The native Windows frame, Winmux mark, six themes, custom terminal fonts and both interface languages remain intact.

Controls stay discoverable through labels, tooltips and visible keyboard focus. Repeated pane actions reveal on hover or focus. Agent hooks are a persisted Behavior setting and remain limited to supported installed agents. No decorative cards, metrics, gradients, animation or placeholder content are part of the interface.

This is an implemented direction, not a generated design approval. Acceptance requires a screenshot of the running Electron app with real terminal content and a responsive check at compact desktop sizes.
